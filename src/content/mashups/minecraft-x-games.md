Minecraft X Games is one repository of experimental mods that each put Minecraft inside another game. Minecraft runs hidden next to the game. The game supplies the shape of its world, and Minecraft supplies the player's movement, blocks, hand and hotbar, so you walk, build, break, fight and blow things up by Minecraft's rules.

There's one release per game: **RedCraft** (Red Dead Redemption 2 story mode, up to v3.0.0), **CyberCraft** (Cyberpunk 2077, v2.0.0), **GTACraft** (GTA V, v2.0.0 on 10 October 2026), **PeakCraft** (PEAK) and **ReadyCraft** (Ready or Not). Each zip includes a setup README for that game and the full source. All of them need [SkyCraft](/mashups/skycraft-minecraft-in-skyrim/) installed, because they drive the Minecraft that SkyCraft sets up, and only one can run at a time.

Moxxie posted RedCraft, GTACraft and CyberCraft separately in the chasm Discord, tagged as experimental. The repository doesn't say whether an AI agent was used and has no AI co-author trailers, so it's marked unverified. It has no licence file.
