FortressCraft runs Team Fortress 2 inside Minecraft: Java Edition, so TF2's classes fight across Minecraft terrain, blocks and mobs. The repository's description says it was "Made using Claude x ChatGPT." On 10 October 2026 it got its first packaged releases under the name **FortCraft** (v0.1.0, then v0.2.0 the same day), with separate Windows and Linux zips: run `START-HERE.cmd` on Windows or `setup.sh` on Linux. It needs Team Fortress 2 and Source SDK Base 2013 Multiplayer from Steam plus Minecraft: Java Edition. The project is labelled work in progress, and is featured in the chasm Discord's project showcase.
