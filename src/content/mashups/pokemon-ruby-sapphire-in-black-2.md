This project rebuilds Pokémon Ruby and Sapphire's Hoenn region inside Pokémon Black 2 on the Nintendo DS. It ships patches only, which you apply to a copy of the game you own; no game data is distributed. It builds on the pret decompilations of the Game Boy Advance games and the pokebw2 decompilation of Black 2. The README says "Anthropic's Claude wrote most of the code and tooling." Release v16.1 had 569 downloads by 9 October 2026. The repository has no licence file.
